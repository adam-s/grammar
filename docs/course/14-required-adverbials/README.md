# Lesson 14 — When an adverbial is required

Researched 28 August 2026. An author's dossier. See
[../01-introduction/README.md](../01-introduction/README.md).

**Status:** This dossier measures the built corpus. [sentences.md](sentences.md) proposes replacements that are not yet parsed or accepted as course data.

## What the lesson decides

| Decision          | In plain words                     |
| ----------------- | ---------------------------------- |
| `form:P`          | this word is a preposition         |
| `form:PP`         | this run is a prepositional phrase |
| `form:Adv`        | this word is an adverb             |
| `form:AdvP`       | this run is an adverb phrase       |
| `func:adverbial`  | it says how, when, where or why    |
| `func:complement` | it completes the preposition       |

**Six decisions, the largest jump in the whole course.** Four new forms and two
new functions in one lesson, because an adverbial has to be made of something
and the something needs naming at the same time.

## The test the lesson is named after

**Removal.** Take the adverbial out. If a whole sentence is left, it was
optional; if what is left is broken, it was required.

_The keys are on the table_ → _\*The keys are._ Required.
_The children played outside_ → _The children played._ Optional.

## The finding

**The lesson contains no optional adverbial at all.** Every one of its ten
adverbials is marked obligatory, so the removal test has nothing to reject and
the learner can answer "required" ten times without looking.

**The first optional adverbial in the entire course is at lesson 16**, two
lessons after the lesson that exists to distinguish them.

**And every verb in the lesson is _be_.** The ten are _are, is, were, is, are,
was, was, is, was, are_. So the required adverbial is only ever shown in one
frame. The other frame the lesson's title promises — a verb that requires both
an object and a place, _She put the letter on the desk_ — does not appear here
at all. It appears in lesson 15.

## Shortcut register

| Shortcut                                          | What defeats it                                                          | In the course?                     |
| ------------------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------- |
| Every adverbial is required                       | any optional one                                                         | **no** — 10 obligatory, 0 optional |
| _be_ plus a place phrase means required           | a non-_be_ verb requiring a place                                        | **no** — all ten are _be_          |
| A prepositional phrase after _be_ is an adverbial | _The fault was in the wiring_ is fine, but _He is in charge_ is arguable | not tested                         |

Two distinct asked-shapes.

## What this should change

This is the most clearly broken lesson in Stage 2, and the fix is matched pairs.

1. **Review the proposed matched pairs.** _She placed the box under the bench_ /
   _She opened the box under the bench_ holds the words still and makes the
   removal test do real work.
2. **Keep the non-_be_ frames in the proposal.** _She put the milk in the
   fridge_ and _She placed the files on the desk_ avoid the disputed claim that
   _lead_ always requires a place phrase.
3. **Consider splitting the lesson.** Six decisions is a lot, and four of them —
   `P`, `PP`, `Adv`, `AdvP` — are word classes rather than the lesson's actual
   idea. Lessons 18 and 19 later teach nothing new precisely because it all
   arrived here.

## Sources

The removal test is standard and is stated in the app's own `obligatory` field.
No external source was needed or read for this lesson; the finding is entirely
from the corpus.

## Rejected

- **Teaching "adverbial" by its four questions — how, when, where, why.** That
  is the app's own hint and it identifies adverbials fine. It says nothing about
  whether one is required, which is what this lesson is for.
