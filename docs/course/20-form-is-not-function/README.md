# Lesson 20 — Form is not function

Researched 28 August 2026. An author's dossier. See
[../01-introduction/README.md](../01-introduction/README.md).

**Status:** This dossier measures the built corpus. [sentences.md](sentences.md) proposes replacements that are not yet parsed or accepted as course data.

## What the lesson decides

**Nothing new** — and it is the most important lesson in the course anyway,
because it is where the app's whole doctrine becomes visible.

## The finding: this lesson is built correctly

**Five matched pairs.** Each pair holds the prepositional phrase word-for-word
identical and changes what it is doing:

| Required                                             | Optional                                      |
| ---------------------------------------------------- | --------------------------------------------- |
| _They put the piano **in the hall**._                | _The quartet rehearsed **in the hall**._      |
| _Another porter laid the tray **on the sideboard**._ | _The cat slept **on the sideboard**._         |
| _The clerk placed the deeds **under the counter**._  | _The draught whistled **under the counter**._ |
| _She placed the lamp **beside the bed**._            | _The nurse waited **beside the bed**._        |
| _The carpenter set the beam **across the gap**._     | _That rope swung **across the gap**._         |

Same form, different function, and the only way through is the removal test. No
counting, no position, no heading.

**This is the design the rest of the course should copy**, and the criticism in
these dossiers of lessons 8 to 14, 17, 18, 25 and 27 amounts to saying they are
not lesson 20.

Its three distinct asked-shapes look low and are not a defect: the pairs are
_meant_ to look alike.

## The test

**Removal.** _The quartet rehearsed._ survives. _\*They put the piano._ does not.

This is lesson 14's test, and lesson 20 is the first place in the course where
it has anything to reject — because lesson 14 itself contains no optional
adverbial at all.

## Shortcut register

| Shortcut                                          | What defeats it                  | In the course? |
| ------------------------------------------------- | -------------------------------- | -------------- |
| A prepositional phrase after the verb is optional | the left column                  | **yes**        |
| The same words always do the same job             | every pair                       | **yes**        |
| Position decides                                  | both members put the phrase last | **yes**        |

Three of three defeated. No other lesson in the course scores this.

## What this should change

**Nothing.** Move lesson 14's missing contrast here, or move some of this here.
The lesson itself needs no work.

## Sources

Entirely from the corpus, measured 28 August 2026. The form-function separation
is the app's own doctrine and is documented in `src/lib/grammar/types.ts`.

## Rejected

- **Renaming the lesson.** "Form is not function" is abstract for a title and it
  is exactly right, and the sentences make it concrete before the phrase has to
  mean anything.
