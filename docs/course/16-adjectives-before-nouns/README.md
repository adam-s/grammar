## What the lesson decides

| Decision           | In plain words                         |
| ------------------ | -------------------------------------- |
| `func:premodifier` | it sits before the head and narrows it |

**`form:Nom` used to be taught here and moved to lesson 5 on 28 August.** The
reason is in [../05-find-the-head/README.md](../05-find-the-head/README.md): a
noun's head sits _inside_ the `Nom`, so while `Nom` arrived at 16 every lesson
before it could only ask for a head on a noun phrase with nothing else in it —
which is exactly a noun phrase with no competitor. Lesson 5 could not teach its
own subject.

The move costs this lesson nothing. No lesson between 5 and 15 has a `Nom` in
its sentences, so not one of their targets changed.

## The finding: this is the best-composed lesson in Stage 3

**Six distinct asked-shapes,** and the reason is that it deliberately puts the
new premodifier inside every verb type from Stage 2:

| Sentence                                     | Frame reused       |
| -------------------------------------------- | ------------------ |
| _The narrow gate jammed._                    | intransitive       |
| _The clerk filed the urgent report._         | transitive         |
| _The new tenant seemed nervous._             | linking            |
| _The porter handed the tired guest a key._   | two objects        |
| _That jury found the young driver careless._ | object complement  |
| _The heavy crate is on the ramp._            | required adverbial |

That is what composition looks like, and no other lesson in Stage 3 does it as
thoroughly.

## The tests

**Order.** An adjective goes between the determiner and the noun. A determiner
cannot go there: _\*narrow the gate_.

**Comparative and predicative.** From lesson 6's tests, run the other way: a true
adjective takes _-er_ and follows a linking verb. _narrow → narrower_, _the gate
is narrow_. A determiner does neither, which is what separates _narrow_ from
_that_.

## Shortcut register

| Shortcut                                  | What defeats it                                 | In the course?            |
| ----------------------------------------- | ----------------------------------------------- | ------------------------- |
| The word before the noun is the adjective | a noun premodifying a noun, _the kitchen clock_ | **no**                    |
| One adjective per noun phrase             | stacked adjectives                              | **no** — all ten have one |
| Adjectives only appear before nouns       | _seemed nervous_ — lesson 10                    | **yes**                   |

## What this should change

1. **Stack two adjectives once.** _The bright red kite_ raises the question of
   whether they are siblings or nested, which is a real `Nom` question.
2. **One noun premodifying a noun.** _the kitchen clock_. It is the commonest
   thing that looks like an adjective and is not.
