## The tests

**"Verb what?"** _The mechanic replaced — what? — the belt._ Fast, and it is a
question rather than a test: it finds the object when there is one and does not
tell you whether there had to be one.

**The passive.** A direct object can become the subject: _the belt was replaced_.
This is the test, and it is unavailable until lesson 37.

**Substitution.** The object is a noun phrase, so _it_ or _them_ replaces the
whole run. This is reachable now and is the only formal test the lesson can
actually run.

## Shortcut register

| Shortcut                                     | What defeats it                                     | In the course?                        |
| -------------------------------------------- | --------------------------------------------------- | ------------------------------------- |
| The noun phrase after the verb is the object | a subject complement, a required adverbial          | **no** — everything here is an object |
| Any verb with a noun after it is transitive  | _He is a doctor_, _The archive is below the stairs_ | **no** — those are lessons 11 and 14  |
| Five words means transitive                  | anything else                                       | no                                    |

Two distinct asked-shapes. All ten are `NP V NP.`

The lesson heading answers the question. Nothing in lesson 9 could be
intransitive, so no learner has to test anything, and the frame is given before
the sentence is read.

_She answered the question_ is here; _answer_ is also intransitive. _The storm
damaged the roof_ is here; nothing in the lesson does not take an object.

## What this should change

1. **One intransitive sentence in the cumulative band.** The ergative pair costs
   nothing and is available now: _The gate opened._ / _She opened the gate._
   Same verb, one object, no object.
2. **Name the substitution test.** It is the only one that works before
   lesson 37.
