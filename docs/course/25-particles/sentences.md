# Lesson 25 — Particles · sentences

Drafted 28 August 2026. See [README.md](README.md).

**The shortcut:** every particle in all ten built sentences sits immediately
after the verb, so the movement that _proves_ something is a particle never
happens. And no preposition appears in the same position to be confused with.

Four tests exist and the built lesson uses none:

- **Movement.** A particle goes behind the object; a preposition cannot.
- **The pronoun.** _looked it up_ ✓ against _\*looked up it_ ✗.
- **Adverb insertion.** You can put an adverb before a preposition, not before a particle.
- **Stress.** A particle takes it; a preposition does not.

## Sentences

| #   | Sentence                            | The step                                           |
| --- | ----------------------------------- | -------------------------------------------------- |
| 1   | She switched off the lamp.          | the particle where the built lesson always puts it |
| 2   | She switched the lamp off.          | **the same words, particle moved**                 |
| 3   | The crowd cheered him on.           | a second verb, particle first                      |
| 4   | We wrote down the address.          | **moved again, so item 2 was not a one-off**       |
| 5   | We wrote the address down.          | a particle                                         |
| 6   | She looked up the number.           | **the same three words, a preposition**            |
| 7   | She looked up the chimney.          | a particle in a longer frame                       |
| 8   | The children picked up the litter.  | **the same shape, a preposition**                  |
| 9   | The children climbed up the ladder. | a pronoun object, which forces the movement        |
| 10  | The clerk took every name down.     | movement over a longer object                      |

## Notes

Items 5 and 6 are the sharpest pair in the lesson. _looked up the number_ and
_looked up the chimney_ differ in one noun and in what _up_ is. Only the tests
separate them: _looked it up_ ✓ against _\*looked it up the chimney_, and _She
looked the number up_ ✓ against _\*She looked the chimney up_.

Item 9 is free evidence. With a pronoun object the particle **must** move —
_\*cheered on him_ is not English — so the sentence runs the test without anyone
being asked to.

Items 2, 4 and 10 move the particle over objects of increasing length, which is
the one place in this lesson where a longer object earns its words: _took every
name down_ is harder to hold than _wrote the address down_.
