# Lesson 25 — Particles · sentences

Drafted 28 August 2026. See [README.md](README.md).

**Status:** the table below is the live course text. Where this page measures a
corpus — shortcuts, counts, what was missing — it measures the one these
sentences replaced; the notes under the table describe what is built.

**The shortcut:** every particle in the ten sentences this replaced sat
immediately after the verb, so the movement that _proves_ something is a particle
never happened. And no preposition appeared in the same position to be confused
with.

Four tests exist, and that lesson used none of them:

- **Movement.** A particle goes behind the object; a preposition cannot.
- **The pronoun.** _looked it up_ ✓ against _\*looked up it_ ✗.
- **Adverb insertion.** You can put an adverb before a preposition, not before a particle.
- **Stress.** A particle takes it; a preposition does not.

## Sentences

| #   | Sentence                            | The step                                            |
| --- | ----------------------------------- | --------------------------------------------------- |
| 1   | The children picked up the litter.  | a particle, and the object comes after it           |
| 2   | The clerk took every name down.     | movement over a longer object                       |
| 3   | She switched off the lamp.          | a particle before the object                        |
| 4   | She switched the lamp off.          | **particle moved**, against _switched off the lamp_ |
| 5   | The crowd cheered him on.           | a pronoun object, which forces the particle to move |
| 6   | We wrote down the address.          | the particle directly after the verb                |
| 7   | We wrote the address down.          | the same verb, particle behind the object           |
| 8   | She looked up the number.           | **a particle** — _look up_ is one verb here         |
| 9   | The children climbed up the ladder. | **a preposition** — _up the ladder_ is one phrase   |
| 10  | She looked up the chimney.          | **a preposition** — _\*looked the chimney up_ fails |

## Notes

_She looked up the number_ and _She looked up the chimney_ are the sharpest pair
in the lesson. They differ in one noun and in what _up_ is. Only the tests
separate them: _looked it up_ ✓ against _\*looked it up the chimney_, and _She
looked the number up_ ✓ against _\*She looked the chimney up_.

_The crowd cheered him on_ is free evidence. With a pronoun object the particle
**must** move — _\*cheered on him_ is not English — so the sentence runs the test
without anyone being asked to.

_The clerk took every name down_, _She switched the lamp off_ and _We wrote the
address down_ move the particle over objects of increasing length, which is the
one place in this lesson where a longer object earns its words: _took every name
down_ is harder to hold than _wrote the address down_.
