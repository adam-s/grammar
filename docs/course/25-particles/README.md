# Lesson 25 — Particles

Researched 28 August 2026. An author's dossier. See

## What the lesson decides

| Decision        | In plain words             |
| --------------- | -------------------------- |
| `form:Part`     | this word is a particle    |
| `func:particle` | it belongs to the verb     |
| `part:verbal`   | the kind of particle it is |

## The tests

Four exist and the lesson uses none of them.

**Movement.** This is the definitive one. A particle can go behind the object; a
preposition cannot.

> substitute a personal pronoun for the object … If it can be arranged before
> the particle/preposition and still make sense, then a particle is being used

_She looked up the number_ → _She looked **it** up_ ✓ (particle)
_She looked up the chimney_ → _\*She looked **it** up_ ✗ (preposition)

**Adverb insertion.** You can put an adverb between a verb and a following
preposition, but not between a verb and its particle.

**Stress.** A particle takes the stress; a preposition does not.

**Fronting.** A preposition can move to the front of a question or relative
clause. A particle never can.

## The finding

**Every particle in all ten sentences sits immediately after the verb.** _wrote
down the address, shut off the valve, looked up the number, turned down the
offer, put away the crates, called off the search, drew up a schedule, took apart
the scaffold, pointed out the fault, threw out the furniture._

The movement that _proves_ something is a particle never happens. Two distinct
asked-shapes.

**And no preposition appears in the same surface position to be confused with.**
_looked up the number_ against _looked up the chimney_ is the whole lesson in
two sentences, and only the first is in the course.

## Shortcut register

| Shortcut                                            | What defeats it             | In the course? |
| --------------------------------------------------- | --------------------------- | -------------- |
| The word after the verb is the particle             | _looked up the chimney_     | **no**         |
| A particle is a short word like _up_, _down_, _off_ | those are also prepositions | **no**         |
| The particle comes before the object                | _She looked it up_          | **no** — 10/10 |

Three of three, unchallenged.

## What this should change

1. **Move a particle.** _The clerk wrote the address down_ beside sentence one.
   One sentence, and the lesson's central test becomes runnable.
2. **Add the preposition twin.** _looked up the number_ / _looked up the
   chimney_.
3. **The pronoun test is free.** _She looked it up_ is four words and it is the
   cleanest evidence in the lesson.
