# Proposal review ledger

Regenerated 28 August 2026 from the live corpus in `src/lib/course/sentences/`.

This is authoring evidence, not learner-facing metadata. A reading may be marked
reviewed in `provenance` only after all four fields here are resolved for it.
"Probe passes" means the construction survives the grammar audits and the label
sweep; it does not approve this sentence's parse, reading, or lesson scope.

`scripts/check-sentences.mjs` holds this file to the documentation tables and
the documentation tables to the built course, and fails if this file is missing —
a check that skips when its input is absent is a check that passes by not
running.

Status values:

- **Pending human review:** nobody has accepted the ordinary reading yet.
- **Step recorded; parse built:** the row names the intended work and the parse exists.
- **Pending reach audit:** accumulation and lesson scope have not been measured.
- **Audits and sweep pass:** well formed and reachable through the real palette.
