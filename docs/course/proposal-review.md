# Proposal review ledger

Created 28 August 2026 from the 44 `sentences.md` files.

This is authoring evidence, not learner-facing metadata. A sentence may move into
the built corpus only after all four review fields are resolved. “Probe passes”
means the smallest construction survives the grammar audits; it does not approve
this sentence’s parse, reading, or lesson scope.

Status values are deliberately explicit:

- **Pending human review:** nobody has accepted the ordinary reading yet.
- **Step recorded; parse pending:** the sentence table names the intended work,
  but no proposal parse exists.
- **Pending reach audit:** accumulation and lesson scope have not been measured.
- **Probe passes; fixture pending:** the model can draw the construction, but the
  fixture/corpus evidence is still incomplete.
- **Blocked:** the current model cannot represent the proposed construction.
