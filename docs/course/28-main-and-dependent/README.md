## What the lesson decides

| Decision       | In plain words                           |
| -------------- | ---------------------------------------- |
| `form:Cl`      | this run is a clause inside a bigger one |
| `kind:nominal` | it is doing a noun's job                 |

The stage turn. Up to here each target sentence had one clause; from here one
clause can sit inside another.

## The finding

**Every nominal clause in this lesson is a direct object, and none has a
marker.** _She knew the belt broke. The driver said the engine stalled._ Ten
times, with no _that_.

That is scope working correctly, not an oversight: `form:Subord` and
`func:marker` arrive at lesson 29, so _that_ cannot be drawn yet.

But the consequence is worth naming. **Lesson 28 shows only the marker-less
object clause, and lesson 30 shows only the marked subject clause.** Two things
change at once between them: the marker appears and the position moves. Neither
lesson holds one still while the other varies, so the commonest form of all —
_She knew **that** the belt broke_ — appears in neither.

Two distinct asked-shapes. Verb-final 10/10.

## The tests

**Substitution.** A nominal clause is doing a noun phrase's job, so _it_ or
_something_ replaces it: _She knew **it**_. This is lesson 1's test reaching its
furthest point, and it is what makes `kind:nominal` a formal claim rather than a
name.

**It has its own subject and verb.** _the belt broke_ is a clause because it
contains a frame, which is lesson 1 applied inside lesson 28.

## Shortcut register

| Shortcut                           | What defeats it                  | In the course? |
| ---------------------------------- | -------------------------------- | -------------- |
| A nominal clause is the object     | a subject clause — lesson 30     | **no** here    |
| Two verbs means an embedded clause | a coordinated clause — lesson 33 | **no**         |
| A dependent clause has no marker   | lesson 30, and most English      | **no**         |

## What this should change

1. **Hold one variable still.** Once lesson 29 has taught the marker, one
   sentence of the form _She knew that the belt broke_ would let the learner see
   that the marker is optional rather than positional.
2. **Vary the predicate.** Verb-final in all ten again.
