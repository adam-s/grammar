| `func:appositive` | a second noun phrase naming the same thing |

## The tests

**Either one can be removed.** This is what separates an appositive from a
modifier. _The treasurer, a banker, resigned_ → _The treasurer resigned_ ✓ and
_A banker resigned_ ✓. Both survive, because both name the same person. A
postmodifier cannot do this: _The path beyond the gate narrowed_ → _\*Beyond the
gate narrowed_.

**They can swap.** _A banker, the treasurer, resigned._ Order is stylistic.

**`be` links them.** _The treasurer **is** a banker._ Same test as lesson 13's
object complement, one level down — which is worth knowing, because the two
constructions are easy to confuse and the test that joins them also separates
them by where it applies.

## Shortcut register

| Shortcut                                       | What defeats it                   | In the course?             |
| ---------------------------------------------- | --------------------------------- | -------------------------- |
| **The thing between commas is the appositive** | a close appositive with no commas | **no** — 10/10 have commas |
| An appositive begins with _a_                  | _That ferry, Mermaid, sailed_     | **yes**, once              |
| An appositive follows the noun                 | a fronted one                     | no                         |

The first row is the problem. A
learner can find every appositive in this lesson by hunting for commas, and
lesson 39 will later insist that punctuation is evidence rather than definition.

**The close appositive is missing entirely.** _Our guide Arun waved_ has no
commas and a different meaning — it picks out which guide. That contrast is the
whole restrictive/supplementary distinction in four words, and it needs a model
check before it can be built.

## What this should change

1. **Add one close appositive**, if the model can hold it. Check first: nothing
   in either corpus has an appositive without commas.
2. **Point the `be` test at lesson 13.** The two lessons use the same test on
   different constituents and neither mentions the other.
